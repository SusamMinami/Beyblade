# 街头夜景检查

2026-09-16；范围：Web `street` 的 Blender 模型、材质、局部光照、积水反射与装饰动效。
Godot 未迁移。桌面为 1440 × 1000 中的 564 × 1000 游戏画面，手机为 Chrome
390 × 844 视口。截图是当前实际发射准备界面，不是离线效果图。

## 自动检查

- `npm test`：29 项通过。
- `npm run build`：通过，保留既有 Three.js 大于 500 kB 分块提示。
- `npm run verify:worlds`：31 项通过，覆盖地图、发射、碰撞、资产缺失及近景交互。
- `node tools/verify-street.mjs`：10 项通过；明细见 [verification.json](verification.json)。
- Impeccable 对初次完成的渲染文件与地图数据进行单次扫描：无发现，见 [detector.json](detector.json)。此扫描早于独立审阅后的材质修正；未将它当成最终画面质量证明。

街头专项通过真实界面发射；独立渲染容器读取反射纹理，隐藏模型后 320,907
像素发生显著变化，确认是真实模型镜像。验证灯光强度随时间变化、暂停冻结、
减少动态效果常亮、切走后恢复默认灯光。两次重新进入并离开街头后，GPU 纹理和
几何计数回到基线；反射目标收到 dispose 事件。

## 资源与性能边界

`street.glb` 为 6,888,536 字节，40 个按材质合并的网格，251,956 个三角形，
没有外链图片/缓冲区。源 `.blend` 保留独立物件。桌面检查反射目标为 768²，
初次进入窄屏时为 512²；所有积水共用一个目标。

独立渲染检查在计入阴影、反射和后处理后提交 758,992 三角形、139 次绘制。
这些是绘制统计，不是 FPS，也不等同于物理手机性能保证；未进行低端手机实机验收。
矩形面光的 LTC 查找纹理由 Three.js 全局库初始化一次，各街头实例共享；
反复进出不会重复分配。面光查找数据使 Three.js 分块增至约 887 kB，gzip 约 266 kB。
