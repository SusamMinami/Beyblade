# Web 场景与战斗美术

2026-09-16。Web 优先，Godot 场景未迁移。

## 入口

- `http://127.0.0.1:5173/#collection`：缓慢旋转、五路扫光。点击实体陀螺或“近距离查看”进入原场景近景；拖动环视，滚轮或双指缩放，点击零件/零件按钮聚焦。返回舞台后恢复慢转。非近景时左右滑动切换陀螺，沿用先降后升、隐蔽提交配置的流程。
- `http://127.0.0.1:5173/#lab`：新玩家默认童年书桌，白板使用实际计算结果。LV.2 在实验室设置中选择原精密实验室，房间选择随原存档保存。外观不改变测量、风场与经验计算。
- `http://127.0.0.1:5173/#map`：五个场地。原金属高速场升级为冠军科幻竞技场，原标准、复合场保留，新增街头与浮空遗迹。

## 源文件

运行 Blender：

```powershell
& 'C:\Program Files\Blender Foundation\Blender 5.2\blender.exe' --background --python tools/build_battle_worlds.py
```

`tools/art_source/` 保留独立物件、倒角及材质的 `.blend`：

- `championship.blend`：浅碗、分层外壳、透明围挡、带检修缝/六角螺栓/冷却槽的分段甲板、阶梯散热设备组、桁架灯塔、吊挂记分屏与电源模块。台阶是竞技装置设备，不是缩小的人类座椅。
- `childhood_lab.blend`：木桌、切割垫、玩具盘、白板、窗户与庭院树冠、蓝色台灯、文具、收纳架、玩具盒与笔记本。
- `street.blend`：支持日夜的雨后街角。咖啡店的瓷砖墙裙、橱窗杯具、木门、条纹雨棚、日文灯箱；旁边是卷帘门自行车店、售货机、带辐条/挡泥板/链条/气门嘴的自行车、带口沿及托盘的盆栽、长凳、菜单牌。楼上有窗帘、空调百叶与管线，街边有路缘石、排水沟、井盖、电线与路灯。生活物件按成人尺度分组布置；玩具盘、装备箱与发射器维持原尺寸。
- `floating_ruins.blend`：石台、裂纹石板、实体障碍、残柱、水晶、符文、楼梯、门楼与远方浮岛。

`resources/battle_worlds/` 是按材质合并的运行时 GLB。街头约 7.93 MB。所有装饰、店名、标志为本项目制作；没有将参考截图用作背景。这是实时风格化模型。

冠军场独立生成器为 `tools/build_championship_scene.py`，完整重建也调用它。
运行以下命令仅重建冠军场（约 6.66 MB），并导出 `championship_layout.json`
供运行时读取六处灯头锚点和两圈跑灯位置：

```powershell
& 'C:\Program Files\Blender Foundation\Blender 5.2\blender.exe' --background --python tools/build_championship_scene.py
```

街头的独立生成器为 `tools/build_street_scene.py`，全场景生成器也委托它生成街头，避免重建时覆盖为旧版。只重建街头：

```powershell
& 'C:\Program Files\Blender Foundation\Blender 5.2\blender.exe' --background --python tools/build_street_scene.py
```

生成器默认从 Windows 的 `YuGothM.ttc` 读取日文字形并转成网格，不在运行时分发字体文件。其他工作站通过 `STREET_FONT` 环境变量指定可用的日文字体；缺失时明确报错。

### 街头比例与生成数据

默认配置陀螺在战斗缩放 `.92` 后宽约 `1.99`，车轮直径 `21.76`，门高 `68.48`，
分别约为陀螺直径的 11 倍和 34 倍。生活用品相对旧微缩版扩大 16 倍，再按组重新
布置；近景看到车轮、花盆和门槛的局部，店面上部自然出画。不要为了显示整栋楼
再次缩小生活物件。地面、路缘与排水设施分别重建，盘半径仍是 `6.7`。
上述为渲染比例校准，不是游戏质量、尺寸单位的变更。

同次导出生成 `street_layout.json`，记录模型测得的关键尺寸及灯具位置。
运行时直接读取灯具锚点，防止模型放大后光源仍停留在旧位置。Blender 源文件
按店面、自行车、盆栽、路灯等 Collection 保持可编辑；GLB 继续按材质合并。

## 碰撞与数值

冠军场保留原 `metal` ID、低摩擦金属表面和全部平衡参数；街头复用标准碗参数。遗迹使用标准表面、方形边界和四个不可破坏石墩，平面没有碗形回中心力。现有陀螺属性、价格、库存和材料计算不变。

`collision_manifest.json` 由建模脚本导出；遗迹四个内场石墩与八个外围柱脚的中心、半尺寸同时供建模与求解器使用。方形边界限制陀螺中心，以陀螺碰撞半径匹配围栏内侧；高速越界延续既有出界规则。求解器处理圆形陀螺与矩形石墩的接触、重叠修正和回弹。边缘风险按方形轴距计算，角落不会误按圆形出界。新地图不宣称已兼容外部服务器，网络协议仍为原有独立系统。

后续 Web v4 增加局部损伤、接触反冲和轮换加速区，见 [结构战斗](structural_battle_design.md)。
地面 A/B/C 标记由 `drive-zone-model.js` 按真实盘面高度构造，可随场景释放，
不是修改 Blender 地形或新增水面物理。遗迹使用较小供能半径以避开实体石墩；
圆盘使用 1.25，遗迹使用 1.0，坐标和 AI/补转使用同一份数据。

## 动态效果

两色运动拖尾、三层旋转能量弧、碰撞火花、冲击环、局部瞬时补光与短促镜头震动。碰撞驱动场景青色/紫色灯带向橙色过渡，临界转速或出界风险对应红色。特效随机只在渲染端使用，不影响战斗确定性。火花池 192 槽，轨迹每方 48 点，冲击环上限 24。

暂停冻结战斗特效时间。系统减少动态效果时关闭扫光运动、能量弧、拖尾、闪光和震动，保留必要的状态及操作反馈。材质、阴影沿用 Three.js 渲染；未加入真实体积雾、破坏地形或虚构技能按钮。

### 比赛时段与街头日夜

五张战斗地图共用顶部时段选择：随本地时间、白天、夜晚。写入既有 v2 存档的
`sceneTime`；缺省与非法值归一为 `auto`。自动模式在进入地图/比赛时读取玩家本地
时钟，`06:00 ≤ 时间 < 18:00` 为白天，本局开始后保持不变。自由对战和故事远征
共用选择；地图预览可立即切换，无需重新加载 GLB。手机旋转/改尺寸后卡片仍保持
选定地图居中。

`scene-time.js` 生成两套天空、地面反弹与柔光源环境探针，按需缓存至 renderer
销毁。白天改变日光方向、天空填充、反射环境与雾色；街头店灯自发光降至约 6%，
局部灯光降至 4%，保留自然的玻璃/釉面/塑料反光。夜晚恢复暖店灯与冷夜色。
非街头地图保留各自几何和材料；本次生活尺度建模集中在街头。

`web-prototype/src/render/street-atmosphere.js` 为街头单独提供冷色夜光、六处局部点光及四处矩形面光（橱窗、售货机、路灯柔光和天空反光）。面光在带涂层的象牙色塑料和湿地上形成宽而柔和的反光，盘面中心比边缘更粗糙。瓷砖、漆面、玻璃、布面、灰泥、木材和细颗粒湿沥青保持材质分离。橱窗为真实开口，内部有低自发光的后墙、货架、杯具、独立照明与薄玻璃。地图选择和战斗使用同一套夜景光照；离开街头恢复其他场景的照明。

塑料额外使用日夜两套柔光环境探针：夜间暗底、暖色长条光源与冷色天空光源；
白天明亮天空与柔日光。这个美术定向探针只供盘面材质使用，随街头销毁；
它与下述实时路面积水镜像是两个独立效果。釉面砖、漆面与玻璃使用涂层物理材质。

店招、售货机与纸灯笼采用连续微幅明暗变化，关联局部光源同步变化，不做频闪。四处不规则积水区域共用一个真实平面反射目标；遮罩避开战斗盘，镜像来自场景模型，加入不均匀干湿间隙、变化的柔化程度和缓慢噪声扰动。窄屏初次加载使用 512²，其他尺寸使用 768²，不逐水洼增加渲染目标；反射会增加一次场景绘制。光照、细节和积水只影响渲染，未改变战斗表面、摩擦或碰撞。

暂停冻结灯光与水面时间。减少动态效果时保持静态反射和常亮灯光。场景切换与销毁释放反射纹理、几何及局部灯光；异步加载的旧场景不会在销毁后重新挂载。

### 冠军竞技场移动照明

`championship-atmosphere.js` 为冠军场提供六个真实聚光灯及同步转向的灯头，
青色与冰蓝光束以不同相位交叉扫过盘面；两圈各 96 段的周边灯轨反向运行。
几何光锥采用透明加法着色并柔化边缘，不是真实体积雾。聚光灯实际作用于
模型表面，使用现有环境反射和主方向灯阴影，不新增六套阴影或实时反射目标。
盘面、抛光边条和石墨漆面转换为带清漆层的物理材质，保留程序化细磨纹。

白天降低光束、跑灯和灯具发光强度，采用明亮天空与较轻的距离雾；
夜晚提高局部照明与少量泛光，保留青色/冰蓝和金属亮暗层次。碰撞对局部
照明和跑灯做小幅增强，已有能量材料继续承担风险颜色。灯轨只作装饰；
黄色 A/B/C 区的玩法与碰撞参数保持原有定义，盘半径仍为 `6.9`。

暂停及页面隐藏时冻结扫光/跑灯时钟；减少动态效果时固定灯头与灯轨，
光束降低至对应时段的一半。退出场地会移除聚光灯、光锥和灯轨并释放
共享几何/材质，主场景继续负责模型材质销毁。旧通用双聚光灯在冠军场禁用，
离开冠军场后恢复目的地的照明设置。

溢出、模型相对比例、原盘面参数、反射目标中的模型像素、灯光变化、暂停、减少
动态效果、五图白天加载及反复切换的 GPU 资源释放。截图和测量保存于
`.impeccable/review/street-scale/`，旧 `.impeccable/review/street/` 为先前微缩夜景的
历史证据。手机截图来自 Chrome 视口模拟，不等同于低端手机 GPU 性能认证。

截图与测量保存在 `.impeccable/review/championship/`。测量报告中的三角形数
包括主阴影绘制和后处理提交，不代表单份模型的面数。
