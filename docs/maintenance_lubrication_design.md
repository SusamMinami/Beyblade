# 模型保养：当前实现与后续物理研究

核对：2026-09-30。先 Web，验收后再移植 Godot。
首期直接涂抹已实现；数值为游戏平衡近似，没有实物工程标定。
本文取代原始研究稿中的重复实施步骤和过期代码快照。

## 已确认的交互边界

保养是可跳过、可试验、可擦回的装备互动。部件进入时**自动展开**，
不设置开盖、绕过外壳或组件遮挡谜题。功能面应方便触达，涂错可直接擦回。
不增加油品商城、耗材收费、日常保养任务、离线劣化或强制维修；
默认设备维持原有正常性能。活动轴尖、自由环等在结构真正加入后再扩展。

## Web 已实现

入口是 `/#assembly` 的“保养”，旧 `/#maintenance` 自动映射到同页工具。
沿用纸色、黑字、蓝色控件，与真实陀螺、发射器共用当前实验室房间。
房间成长见[共享实验室](home_lab_integration.md)，九件换装见
[发射器运行时](launcher_runtime.md)。

- 使用当前 `launcher-performance.glb` 真实三槽配置；发射器与传动内部自动展开，
  陀螺五件自动展开，轴尖接地区域朝向观察者。
- 表面拖动滴油或擦拭，三档出油量、24 步撤销、擦净当前、部位近景、环绕和缩放。
  双指转为观察并撤回未完成误滴；触摸取消、失焦、隐藏页面撤回当前笔。
- 油膜存网格局部坐标、法线、区域、油量，读数和画面共用记录。
  每网格最多 48 点，每模型/陀螺部件最多 192 点；达上限可擦拭腾位，
  不静默删除旧记录。油膜随运动节点移动，薄件正反面独立。
- 工作面依据 `surfaceRole`，握柄仅胶垫、陀螺仅轴尖下部接地面影响相应性能。
  外壳、螺钉、弹簧与其他非工作表面只留下可擦油膜。
- 对照试拉固定 86% 输入、标准平面、无碰撞与供能，调用现有
  `BattleSimulation` 180 步；比较初始转速、偏向、3 秒滑行和发射器能量/释放读数。
  滑行和转速为游戏单位，不是米、RPM 或实测续航。慢速机械展示是运动学近似，
  减少动态效果时停用，不影响数值对照。

保存同时提交保养及已装入的发射器草稿，留在当前工具，下一场普通/剧情战生效。
同页切工具、换房间保留草稿；撤回返回陀螺组装，离开组装放弃未保存修改。

首场固定配置教学保持默认。发射器保养共享，陀螺按“配装槽 ID + 零件 ID”保存；
换件不把油转给新件。沿用 v2 存档 `maintenance` 字段，旧档默认干净；
不改所有权、金币、DIY 或出战槽，不消耗耐久。

## 当前物理因果

### 传动与有限能量

传动面合计油量 `q` 的等效效率：

```text
excess = clamp((q − 6) / 12, 0, 1)
η = clamp(0.72 + 0.16 × (1 − exp(−q / 2.2)) − 0.22 × excess², 0.5, 0.88)
ω / ωref = sqrt(η / 0.72 × retainedWork)
```

由 `launcher-physics.js` 统一结算输入做功、部件残留能、释放损耗和转速上限。
上式是原装参考配置的润滑关系；不乘前向发射速度，不改零件最大转速属性。
同一份输入不能在效率、部件加成和润滑路径重复计算。

```text
W = ∫ Fpull dx
陀螺旋转能 + 发射器残留能 + 回位储能 + 总损耗 ≤ W + 初始储能
ω0 = sqrt(2 × Etop / Itop)
```

单位为自洽的规则能量/惯量，不称焦耳。固定做功、固定拉力、固定抽速是不同试验。
固定齿比和抽速时，润滑主要改变所需拉力；不能承诺所有条件下都提速。

### 握柄与接地

主握柄油膜降低支撑阈值，超过后沿抽拉侧产生确定性方向/倾角偏差。
拉柄油膜降低可保持的拉力与有效做功。轻拉不必然打滑，不采用随机准确率处罚；
目前使用固定手部支撑参数，没有手模型或可调夹具。

轴尖油膜降低摩擦上限、滑移松弛率，同时改变制动和可用控制力。
仅修正自然损耗的 35% 接地份额，不修复结构损伤或擦地损耗。
橡胶与其他材料使用不同敏感度且保留下界；过量有附加拖曳。
短程滑行更远、初始转速更高均不等于整场胜率或续航更高。

固定中轴、装配缝、攻击环外表没有内部相对运动，外表上油不获得内部减阻加成。
首期忽略薄油膜质量，因此也不能让单侧多一滴凭空产生巨大质心偏移。

## 后续研究，尚未实现

没有流体铺展/迁移/甩油、油品差异、污物/温度/磨损、独立轴承尖或自由环，
没有完整三维多刚体、接触压力场或连续油膜积分。
当前释放叉、凸轮、卡爪已有联动展示；不等于独立关节接触求解。

### 接触副与油量迁移

先为真实运动件定义局部坐标、材料对、接触副、容量、邻接和运动类型。
部件正反面不互通；迁移只沿明确接触和邻接，不穿过空隙。
规则层有限表面采样，渲染复用贴花/实例，不每滴新建永久材质。
油量使用相对量，不是毫升。每步满足：

```text
旧油量 + 新滴入 = 新油量 + 擦除 + 收集/甩出
```

可研究饱和减阻和积油拖曳模型：

```text
c = 1 − exp(−q / qScale)
e = max(0, q / capacity − 1)
τcontact = max(τfloor, τdry × (1 − a × c) + kD × dirt)
τloss = (τcontact + cv × abs(ωrel) + ce × e² × ωrel²) × tanh(ωrel / ε)
```

这是待标定的游戏近似，不是 SKF 原公式；系数非负、`0 ≤ a < 1`，
`τloss × ωrel ≥ 0`。零速须另补静摩擦约束，限幅冲量避免一步越零反向加速。
供油量不等于真实油膜厚度，不能把 Stribeck 曲线横轴改成滴数。

### 不对称释放与内部转子

卡爪分别求摩擦、载荷、退出时刻后，才能从
`Δv = Σ∫Fi dt / m`、`ΔL = Σ∫(ri × Fi) dt` 得到侧向/倾覆响应。
对称状态分量应抵消，不按屏幕左右或随机数生成偏差，也不把冲量直接当角度。

未来活动尖可先采用双转子：

```text
Δω = ωbody − ωtip
Ibody × dωbody/dt = τexternal,body − τbearing(Δω)
Itip × dωtip/dt = τbearing(Δω) − τground
```

无外力矩时总角动量不变，内摩擦只耗散相对运动能量。
自由环同理，碰撞需明确命中哪一转子；整机惯量在运动件间分配，不能重复计入。
停止判定仍关注主体，润滑不修复裂缝、不让重损陀螺无限保转。
若后来允许大量积油或场地油迹，还须同步质量、惯量、双方接触状态、AI 与回放。
