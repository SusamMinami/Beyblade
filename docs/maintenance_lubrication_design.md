更新于 2026-09-24。适用目标：先 Web，验收后再移植 Godot。
**状态：首期保养已接入 Web；下文保留原始机制研究，未实现提案不代表当前能力。**

## 首期已实现

入口：`http://127.0.0.1:5173/#assembly` 的“保养”模式，
实验室与主页“改装保养”也进入原组装界面。旧 `/#maintenance` 自动映射到该模式，
不再单独开页。保养与原陀螺组装、发射器换装共用真实实验室场景，
沿用原来的纸色、黑字与蓝色控件。按剧情升级与手动选择规则见
[主页与实验室整合](home_lab_integration.md)；下文物理机制不变。

- 保养使用现有 `launcher-performance.glb` 的真实当前配置展开模型。
  发射器三槽九件换装、自由换色和机构联动已经接入，规则见
  [发射器运行时](launcher_runtime.md)；保养检查不代替换装验收。
  模块与传动内部自动展开，陀螺五部件自动展开，轴尖接地面主动朝向观察者。
- 直接在表面拖动滴油或擦拭；三档出油量、24 步撤销、擦净当前模型、
  部位近景、环绕和缩放。双指接管为观察手势，撤回刚开始的误滴；
  触摸取消、失焦或隐藏页面会撤回未完成的一笔。
- 油膜记录网格局部坐标、法线、区域及油量；可见油膜与物理读数使用同一记录。
  每网格最多 48 个采样点，每模型/陀螺部件最多 192 个；到上限后可擦拭腾出位置，
  不静默删除旧油膜。油膜随齿轮节点运动，薄零件正反面独立。
- 工作面识别依据模型 `surfaceRole`，握柄仅胶垫受影响；陀螺仅轴尖下部接地区域
  影响抓地。固定外壳、弹簧、螺钉、非工作表面仅留下可擦油膜。
- “对照试拉”固定 86% 发射输入、标准平面、无碰撞和供能区，运行现有
  `BattleSimulation` 180 步。显示当前与进入时的初始转速、偏向和 3 秒滑行距离。
  读数是游戏平衡单位，不是 RPM、米或实测续航。发射器另有短时慢速机械展示；
  展示不是独立关节求解，减少动态效果时停用。
- 保存后留在当前模式，并用于下一场普通/剧情战斗；组装内切换工具或场景保留草稿。
  “撤回未保存修改”恢复草稿并返回陀螺组装，离开组装放弃未保存修改。
  首场固定配置教学保持默认状态。
  发射器保养共享，陀螺以“现有配装槽 ID + 零件 ID”保存；换件不会把油转给新零件。
  复用 v2 存档中的 `maintenance` 字段；旧存档默认为干净，保存失败保留草稿并提示重试。
  不消耗金币、材料、经验或耐久，不增加离线磨损。

### 接入的物理因果

传动工作面油量合计为 `q`，等效效率
`η = clamp(0.72 + 0.16 × (1 − exp(−q/2.2)) − 0.22 × excess², 0.5, 0.88)`，
其中 `excess = clamp((q−6)/12, 0, 1)`。相同输入做功的轴向转速按
`sqrt(η/0.72 × retainedWork)` 变化，不乘向前发射速度、不修改装备的最大转速属性。
同期换装接入后由 `launcher-physics.js` 统一结算输入做功、部件残留能、释放损耗
和转速上限；上式对应原装参考配置的润滑关系。保养的效率/油污输入仍由本模块提供。

主握柄油膜降低支撑阈值；超过阈值才产生沿齿条抽拉侧的确定性方向/倾角偏差。
拉柄油膜降低可保持拉力和有效做功。轻拉不必然打滑，不采用随机“准确率处罚”。
当前使用固定手部支撑参数，尚无手模型或可调夹具。

轴尖油膜降低地面接触求解器的摩擦上限和滑移松弛率，因此同时改变制动和可用控制力；
只改变自然损耗中约定的 35% 接地份额，结构损伤与擦地损耗不被润滑修复。
橡胶与其他材料采用不同抓地敏感度，均有下界；过量有附加拖曳。
不能把初始转速或短程滑行优势等同于整场胜率、续航提升。

### 尚未实现及版本边界

没有流体铺展、滴落迁移、油品差异、污物/温度/磨损、独立轴承尖、自由环，
没有完整三维多刚体/流体求解器。同期换装工作增加的释放联动是运动展示，
不表示已实现独立接触关节求解。
当前是局部采样汇总到接触区域的降阶模型，不是连续油膜积分或接触压力场。
后续内部活动件先完成结构与运动设计，再接入对应摩擦副。
保养自 Web v5 起接收可选的 `maintenance.player/enemy` 输入；未传入时中性。
当前共享内核、原生状态恢复与网络边界见[第三轮实现](physics_v6_implementation.md)。
本页直接涂抹界面与共享组装场景尚未移植 Godot，不宣称网络权威结算已经兼容。

## 2026-09-23 用户确认的首期范围

先实现发射器传动润滑、握柄油污和轴尖抓地变化。内部轴承尖、自由环等效果，
等设计并加入真正的活动部件后再补齐。

保养沿用 DIY 的部件展开方式，进入后自动展开，玩家可以自由旋转、涂抹、擦拭和试验。
**不增加开盖、组件遮挡、精确绕过外壳等专门提高上油难度的门槛。**
下面原研究稿中“先打开检修盖”“透明盖阻止上油”等操作约束由本条取代；
规则仍区分实际命中的部件和局部油量，但所有功能面应方便触达。
保养的目标是享受与装备互动，涂错、涂多允许轻松擦回，不设消耗品收费或强制保养。

## 原始研究与后续提案（2026-09-23）

以下章节保留当时的研究语境，包括当时的代码快照与待验证方案。

### 设计结论

保养适合做成可跳过、可试验、可擦回的小环节：
打开自己的模型，把油滴在实际表面，拨动部件或试发射，观察动作和数据的变化。
效果由“油是否到达工作接触面、覆盖是否均匀、用量、运动速度、载荷”共同决定。

需要守住四条物理因果：

1. 润滑减少一部分损耗，不产生能量。相同有限做功或拉力条件下可能得到更高转速；
   若齿比和抽拉速度被严格固定，输出转速由运动约束决定，改善的是所需拉力。
2. “发射速度”分为离开发射器时的**自转速度**和**向前速度**。传动润滑主要影响前者；
   不能因为给齿轮上油，就无条件提高横移速度、攻击系数或陀螺自身最大转速。
3. 涂偏不等于必然射偏。偏角必须经过握持打滑、导向间隙或不对称脱扣受力产生。
   对同心、刚性约束完好的轴座，单侧油量差可能只改变阻力，不改变轴线。
4. 只有存在相对运动的接触面，才有对应的内部摩擦可减。固定装配缝和一体中轴
   不因外表抹油获得“续航加成”；需要抓地或锁止的地方，也不总是越滑越好。

第一版建议仅提供一种对游戏内材料设定为兼容的保养油，油量连续、可撤销、可擦拭。
不增加油品商城、消耗品库存、日常保养任务或离线劣化。默认设备保持现有正常性能，
不靠人为恶化旧装备来迫使玩家保养。以上是本提案的范围建议，尚非新增经济规则。

## 当前项目能支持什么

| 已核实内容 | 对保养功能的约束 |
| --- | --- |
| 发射器有八个设计模块；运行时仍载入整体 `launcher.glb`，按材质合为七个网格 | 不能按蓝色/金属材质猜功能部位；需要独立的接触面标记 |
| 模块研究版有八个根节点，但模块内部仍按材质合批 | 更换整模块可复用它；齿轮转动、齿条滑动仍须保留运动节点，不能直接旋转整份芯组网格 |
| 芯组有齿轮、轴/轴座和回位弹簧的视觉对象 | 齿数、齿形、轴承类型、间隙尚未机械标定；不能从外观直接导出齿比 |
| 释放开关只有外部滑钮；拨杆、凸轮、卡爪联动待补 | “单边脱扣导致偏角”属于后续机构设计，不能立即声称已有物理支持 |
| 正式陀螺有 15 件零件、五种槽位；无独立关节/轴承状态 | 当前三个中轴、三个轴尖都不能假定为自由转动轴承 |
| 战斗使用二维位置、整体转速、标量倾角及八扇区结构损伤 | 可扩展确定性接触与阻力；完整三维姿态和关节不是当前能力 |
| 摩擦、控制力和转速衰减在不同路径计算 | 只降低 `build.friction` 会让陀螺滑远，却不会自然降低摇杆牵引或正常自转损耗 |
| 现有实验室给出参数/环境估算，展示旋转是动画 | 保养对照必须调用真实求解器，不能把展示时长或评分当作续航测量 |

## 发射器：位置与正负影响

“先做”表示适合作为下一轮实现目标，不表示该规则现在存在。

| 接触位置 | 适量、到位的作用 | 过量或错位的影响 | 成立条件与实现次序 |
| --- | --- | --- | --- |
| 齿条侧面 ↔ 固定导轨 | 降低滑动阻力、减少黏滑，有限拉力下更顺畅 | 黏滞拖曳；外露积油更容易带入尘粒 | **先做**直线摩擦副。左右不均仅在有间隙和侧向自由度时产生偏载 |
| 齿条齿面 ↔ 输入齿轮齿面 | 减少齿面滑动损耗，更多输入做功传入芯组 | 过量积油增加搅动/拖曳，可能向邻面迁移 | **先做**等效传动损耗。齿轮是形状啮合，不会仅因“太滑”就自动打滑跳齿 |
| 芯组齿轮 ↔ 齿轮 | 降低啮合摩擦和局部发热、噪声 | 过量/过黏可能拖慢；噪声下降不保证效率继续提高 | **先做**成套芯组，齿比单独设定；不直接使用视觉齿数 |
| 转轴 ↔ 轴套/轴承工作面 | 减少起动、运转阻力；轴承类型不同，响应不同 | 黏滞阻力增加；密封轴承外侧滴油可能完全到不了内部 | **先做**可维护轴座；先确定轴套或滚动轴承结构及供油入口 |
| 回位弹簧导向面、回位滑块 | 降低回程卡涩，回位更一致 | 过黏造成回位迟滞；油不改变弹簧刚度和储能 | 需补动作。除非证明弹簧参与发射储能，否则只影响回位 |
| 连接头输出轴的支承面 | 降低支承损耗 | 过量拖曳；轴线被刚性约束时不会凭空偏转 | 与三爪锁止面分开标记，可在基础支承模型中先做 |
| 连接头卡爪的释放滑动面 | 有机会降低脱离阻滞，使释放更一致 | 有独立卡爪运动、载荷和摩擦差时，可能先后脱离、留下侧向冲量 | **后做**，先补释放机构；正向几何锁合不因沾油就直接解锁 |
| 释放开关导轨/凸轮接触面 | 降低按动和脱扣阻力 | 过黏延迟回位；若含依赖摩擦的保持面，保持能力可能降低 | **后做**，当前缺内部机构。滑钮表面和内部导轨不能混为一处 |
| 主握柄胶垫 ↔ 手 | 无传动润滑收益 | 油污降低可用握持摩擦，较大拉力下可能滑移并带来方向/倾角偏差 | 基础握持模型可先做；需显式手部支撑刚度和拉力方向，低于打滑阈值不处罚 |
| 抽拉柄胶垫 ↔ 手指 | 无传动润滑收益 | 更难保持拉力，可能丢失有效行程/做功；不必然改变陀螺方向 | 和主握柄分别模拟，不能统一成“准确率下降” |
| 外壳、上盖、螺丝头 | 初期只产生表面油膜和可擦拭痕迹 | 沿已定义路径流到握柄/机构后才有后续作用 | **先做**无即时性能变化。油不能穿透关闭的检修盖 |

尘粒、腐蚀、长期磨损是现实中的条件性后果，但首期不引入跨日磨损账本。
若后来做污染，只根据实际试验/比赛使用推进，并把“脏了”与“结构被撞坏”分开。
材料兼容性也不能简化成“某种基础油必然损坏所有橡胶”；现实上要核对具体配方。[S2][S3]

## 陀螺：位置与正负影响

| 接触位置 | 可能收益 | 代价或无效情形 | 当前状态 / 建议 |
| --- | --- | --- | --- |
| 现有固定中轴外表、配重盘装配缝 | 没有可确认的内部减阻收益 | 固定零件没有持续相对转动；过量油只可能外溢 | **现有件只呈现油膜**，除非真实到达另一个有定义的接触面 |
| 橡胶平衡尖 ↔ 场地 | 在指定油/材料组合下可能减小滑动阻力或部分接触耗散 | 抓地、转向、刹车能力降低，容易滑出目标区；倾斜后可能更早失稳 | **先做**接触污染，收益与损失同时接入；不能保证整场更耐转 |
| 金属续航尖 ↔ 场地 | 有条件减小接触损耗 | 原本低摩擦，收益可能很小；过量拖曳/油膜破坏/控制下降可能抵消收益 | 与橡胶尖分开定参数，不能统一乘一个续航倍率 |
| 攻击扁平尖 ↔ 场地 | 可能改变滑移和轨迹 | 接触面积和抓地改变会影响突进、制动与出界；“更滑”不等于“主动横移更快” | **先做**，需要接触面的覆盖分布和相对滑动速度 |
| 现有核心锁扣、固定接缝 | 装卸时的滑动面可能更顺畅 | 比赛中本来锁死，润滑不提供旋转收益；锁定风险取决于实际保持结构 | 先只影响保养动作；未建防松机构前不直接降低耐久/触发解体 |
| 未来自由轴尖 ↔ 中轴轴承 | 减少主体与轴尖之间的耦合损耗，主体可能保转更好 | 过量黏滞拖曳；阻尼过低时某些摆动可能更难抑制 | **后做**独立轴尖转速，补真实轴承与关节；保留五件式槽位，不新增影子库存 |
| 未来自由转动外环 ↔ 主体 | 接触后外环能相对转动，可能减少主体的切向损耗 | 传递进攻扭矩的能力也会变化；必须追踪外环角动量 | **后做**，现有三个攻击环不自动变自由环；碰撞需识别接触的是哪个转子 |
| 未来弹簧伸缩轴/活动翼的导向或铰链 | 更易运动、回位，动作触发更一致 | 黏滞迟滞；减阻可能降低原本有用的阻尼 | **后做**自由度、限位和弹簧储能，不用“全属性提升”替代动作 |
| 攻击环/配重盘外表 | 无内部润滑收益 | 接触摩擦变化需实际切向接触模型；外溢到轴尖才影响抓地 | 首期可涂可擦，接触减伤暂不启用；现有碰撞主要是法向冲量近似 |

薄油膜的附加质量预计很小，尚无项目测量支持把它当作配重手段。
首期忽略油质量，并在报告说明；不能同时忽略油质量又让“左侧多一滴”产生巨大质心偏移。
若未来允许明显积油，须同时记账油质量、质心、惯量及甩出的角动量，不能只加失衡惩罚。

## 对着模型操作

这一节是机制所需的交互约束，未做新页面、视觉重设计或产品规则确认。
沿用现有实验室/近景观察和用户实际装备，场景居中，工具退到边缘。

1. **靠近与打开**：从保养入口把当前陀螺或发射器拉近；打开检修盖后内部才可上油。
   模型允许环绕、翻面和双指缩放，不用单独的示意装备代替实际配置。
2. **滴与涂**：选择滴管后点击落下一小滴，按住按固定时间量连续滴，拖动沿表面涂抹。
   出油量依时间/命令步长积分，不按 `pointermove` 次数累加；高刷新率不能出更多油。
3. **避开手势冲突**：查看模式单指旋转；上油/擦拭模式单指操作工具，
   双指观察；提供明确的“转动模型”切换供鼠标/单指使用。按下工具后暂停自动转台。
   `pointercancel`、失焦、第二根手指加入时立即停止出油，不补算后台时间。
4. **看得到因果**：滴管末端对齐表面法线，薄膜随部件移动，积油与薄膜外观有区别。
   只在选中接触区显示“覆盖/积油/滑移”等局部提示；全局不弹“攻击 +10%”。
   提供可选的接触区轮廓与文字读数，不能只凭高光判断是否涂到位。
5. **拨动与试发射**：手动抽动齿条、转动芯组、按释放钮；有独立轴承才允许单独拨动。
   动画读取模拟状态，不能无论用量多少都播同一个“顺滑”动画。
6. **擦拭与恢复**：抹布拖动移走实际命中的表面油，撤销上一笔、恢复保养前状态可用。
   外表擦拭不能隔壳清空内部储油；恢复按钮是明确的试验重置动作。
7. **保存与退出**：试验使用保养草稿；“应用保养”才写入状态，取消丢弃。
   试发射比较不消耗玩家正式状态；减少动态模式仍保留油量、接触区和结果反馈。

油点拾取必须使用最近的真实遮挡面，再转换成部件局部坐标。
透明上盖仍是遮挡物；不能忽略它直接命中内部齿轮。扩大触控辅助只帮助选择可见面，
不能把落在外壳上的油自动吸到最佳润滑区，也不能按屏幕左右决定机构左右。
键盘可先选真实接触区，再使用定量滴油/擦拭按钮，数值走同一套命令路径。

## 推荐物理路线：局部油量 + 接触副 + 少量自由度

目标是**因果完整、能量有账、相同输入可复现的降阶模型**。
沿用现有游戏平衡单位，先不做逐滴流体、有限元或完整三维刚体接触。
工程级预测还缺真实尺寸、材料粗糙度、间隙、载荷、油品曲线和试验标定；
单靠增加粒子数或物理引擎并不能得到可靠精度。

### 1. 油落在哪里、能流到哪里

为模型增加接触区注册：`surfaceId / partId / localFrame / contactPair /
accessState / capacity / neighbours / materialPair / motionType`。
接触副是“两块发生相对运动的表面”，不是一个材质名称。
运动节点和功能 ID 要在模型导出前保留；对原有 `.blend` 源文件作增量扩展。

- 渲染可用局部贴花/油膜遮罩；规则层只保存有限表面小格或接触区小片的油量。
- 环形接触区可分八扇区、必要时加轴向层；直线导轨沿行程分段，并区分左右导向面。
  同一个部件正面和背面不能只因落在同一角扇区就互通。
- 规则油量 `q` 使用明确的“相对油量”，不标毫升或克；各区容量不同，
  一滴也不能把大齿轮和小轴座同时填到相同百分比。
- 每次滴油分配至真实命中邻域；转动/滑动通过已定义接触把油带到另一表面，
  擦拭进入移除账本。只能沿邻接表迁移，不能跨过盖板或空隙瞬移。
- 阶段一只做有限邻域铺展和接触转移；重力流动、离心甩油后续逐项加入。
  开启哪种迁移，视觉才展示哪种动态，不能让画面流走而数值留在原处。
- 每步满足 `旧油量 + 新滴入 = 新油量 + 擦除 + 收集/甩出`，不得为上限裁剪凭空丢油。
  一次转出量不得超过源格现有量，多边转出按总预算限幅。

上油量是表面供油库存，不等于真实油膜厚度。供油到达、相对速度和载荷还会影响
膜的作用；不能把经典 Stribeck 曲线的横轴简单改名为“滴数”。[S1]

### 2. 减少接触损耗，同时增加油的阻力

作为待标定的游戏模型，对适合润滑的每个接触副定义：

```text
c = 1 - exp(-q / qScale)                    覆盖/有效供油的饱和近似
e = max(0, q / capacity - 1)                多余供油

τcontact = max(τfloor, τdry × (1 - a × c) + kD × dirt)
τmagnitude = τcontact
           + cv(c, viscosity) × abs(ωrel)
           + ce × e² × ωrel²
τloss = τmagnitude × tanh(ωrel / ε)
```

这里 `ωrel` 是两表面的相对角速度；直线摩擦副换成相对滑速和阻力。
`τdry` 随载荷和接触几何取值；所有系数非负，`0 ≤ a < 1`。
该表达只构造“饱和减阻 + 黏滞/积油拖曳”，**不是 SKF 原公式或实测拟合**。
握柄、锁止面与地面接触单独使用材料对模型，不能照搬轴承参数。

零速附近需补静摩擦约束：驱动力未超过静摩擦上限则保持静止，超过后转为动摩擦。
不能仅用平滑 `tanh` 公式假装已经模拟了卡涩和起动阈值。
每步限制摩擦冲量，防止从正转一次跨过零速并反向加速。必须有
`τloss × ωrel ≥ 0`；内摩擦只能消耗相对运动的能量。

### 3. 发射：有限输入做功，而非提高 `power`

现有 `launch()` 同时用 `power` 计算转速和向前速度；简单将 `power` 乘润滑倍率，
会把传动收益错误地复制到两个通道，而且满力度时被钳制吞掉。
应在共同的发射初始条件求解器中处理，供 `launch()` 和 `launchExplicit()` 一起调用。

基础阶段保留现有操作，将力度明确解释为经标定的有限做功/拉力曲线：

```text
输入做功 W = ∫ Fpull dx
陀螺旋转能 + 发射器残留动能 + 回位机构储能 + 总损耗 ≤ W + 初始储能
陀螺初始转速 ω0 = sqrt(2 × Etop / Itop)
```

回位弹簧只在确实储能/释能的路径入账。齿轮惯量按齿比平方折算，不能重复计入；
齿比和行程设独立的运动学上限。方向、前向释放速度和倾角保留各自来源。
变量采用自洽的规则能量/惯量单位，不称焦耳；现有视觉 `spinPhase` 的 `0.32`
倍率不是现实弧度标定，不能作为机械齿比使用。

为了保住旧存档基线，可以先用 `Eref = 0.5 × Itop × ωref²` 建立原发射的参考能量，
再标定参考效率 `ηref` 和输入预算 `W = Eref / ηref`。
维护后的传动效率 `η` 必须由接触损耗计算、限制在 `[0,1]`，
有效转速参考为 `ωref × sqrt(η / ηref)`，同时受运动学/输入预算约束。
无保养状态走原路径；有保养的零变化参考状态须与它一致。

仅作能量关系示例：输入预算同为 100，损耗从 20 降至 12，
有效旋转能从 80 变为 88，转速只提高 `sqrt(88/80)-1 ≈ 4.9%`。
这不是本项目的建议加成，也不是已测到的润滑效率。

进一步加入真实抽拉时，积分齿条行程、速度及少量转子状态。
固定拉力、固定做功、固定抽拉速度是不同试验，报告必须说明采用哪一种；
不能以同一张“提速表”概括所有输入条件。

### 4. 射偏：先有打滑或不对称释放，再有角度变化

主握柄先建立接触摩擦上限与有限支撑刚度：
外部拉力反作用产生的保持力/力矩若超过油污后可提供的保持能力，
才积累位移或姿态变化；变化方向来自拉力方向、接触位置和手部支撑。
用很小力度抽拉不应凭空射偏；固定夹具试验中握柄油污不应改变发射方向。

后续补齐卡爪机构后，每个卡爪独立求解摩擦、弹簧/凸轮约束与退出时刻：

```text
横向速度改变量 Δv = Σ ∫ Fi dt / m
角动量改变量 ΔL = Σ ∫ (ri × Fi) dt
```

对称几何、相同载荷和供油时，对应横向/倾覆分量应抵消。
单侧先释放只在仍有接触载荷的时间段留下额外冲量。
角动量变化用 `ΔL = I Δω` 求角速度，再积分姿态；不能直接把冲量当角度相加。

当前 `tilt` 只有幅值。基础阶段可以用有文档说明的简化握持响应生成释放方向/倾角；
要完整表现偏转方向、翻滚和脱扣轨迹，需要扩展姿态/角速度状态。
不得用 `random × 油量差` 冒充机构解算，也不预设偏差一定朝“油多”的一边。

### 5. 陀螺接地：抓地与损耗分开，但来源一致

当前 `build.friction` 是综合平移阻力，`controlForce` 是独立玩法驱动力，
`spinDecayPerSecond` 是综合常量损耗；它们都不是可直接测量的库仑摩擦系数。

基础实现需新增运行时接触状态：

- 由轴尖材料、场地、接触覆盖、滑速求有效抓地比例和耗散变化。
- 同时影响驱动牵引、制动与被动滑动；不能保留原控制力却只降低阻力。
- 保留既有无油行为，使用相对其干净参考接触的比例修正；勿把油状态写回 `PARTS`。
- 转速损耗要先拆出接地贡献，保留空气/材料/结构项，再替换接地项。
  不因一个轴尖沾油，就把全部 `spinDecayPerSecond` 和结构 `spinDrag` 一起打折。
- 基础比例模型明确标注近似；更高阶接触再按
  `vcontact = vcenter + ω × rcontact` 求摩擦冲量，并同时更新线动量和角动量。
  地面摩擦既影响平动也影响自转时，避免把同一份耗散扣两次。
- 摇杆代表现有外部控制输入，不能宣称全局能量守恒；其输入功率、
  加速区供能、重力势能变化和接触耗散必须区分。

首期不让甩出的油改变整张赛场。若未来开放油迹，必须是双方共用的场地接触状态，
同时更新 AI、回放与规则，而不是仅渲染一块会误导玩家的油斑。

### 6. 陀螺内部活动件：用相对速度求解

未来轴承尖可先采用主体 + 独立轴尖两个转子：

```text
Δω = ωbody - ωtip
Ibody × dωbody/dt = τexternal,body - τbearing(Δω)
Itip  × dωtip/dt  = τbearing(Δω) - τground
```

轴承力矩对双方大小相等、方向相反。
无外力矩时总角动量不变，内摩擦以 `τbearing × Δω` 耗散能量。
减少轴承阻力主要减少主体向受地面制动的轴尖传递能量，
不是向主体直接补转。相对速度为零时也不能重复扣一份“内部旋转损耗”。

自由外环同理，但碰撞作用于外环；两转子不能各自获得整机的全部惯量。
启用前把现有总惯量分配到真实运动件，并明确损伤、接触、控制和停止判定读取谁。
自由尖仍转、主体停转时不应凭空续命。主体仍受偏心损伤和擦地约束，
润滑不能修裂缝、恢复材料刚度或使重损陀螺在加速区无限旋转。

## 状态、存档与性能边界

- 保养状态放在现有存档结构内，独立于永久零件属性；旧存档缺失字段时视为
  “没有额外保养”，保持原结果。默认设备可以有设计上的出厂润滑，不把旧装备解释为损坏。
- 初期陀螺沿用现有 DIY 的逻辑，按出战槽 + 正式零件 ID 保存保养状态；
  当前只有一款发射器时按一个共享逻辑发射器保存，并在三槽切换时保持一致。
  这不表示已有可交易的实体零件副本；未来实体库存另作迁移。
- 替换零件后旧件状态留在原键，新件读取自己的状态；取消购买、锁定预览和试用不写入。
  同一零件 DIY 尺寸变化保持局部坐标与油量守恒、重算面密度；
  拓扑改变无法映射时，需在提交前说明并采用明确迁移/重置规则。
- 对局开始复制双方的配置、保养区域状态及规则版本，固定步长推进。
  不读取实时油膜纹理、帧率、墙上时钟或 `Math.random()` 来结算。
- 首期保存的是“保养设置”；回合内油迁移使用独立副本，回合结束不回写日常磨损。
  若以后改为持久消耗，需单独确定试验、弃赛、刷新和中断时的提交规则。
- 新状态需进入完整快照、规范化哈希与验算输入。当前 Web v4 本来就未完成
  Godot/Worker 对齐；保养先限本地验证，不能只改协议版本宣称联网兼容。
- 油状态校验有限值、合法区域、非负量和预算上限。拒绝未知部件/区域，避免
  非法存档绕过覆盖/容量限制；默认迁移不能改变所有权、金币、DIY 或当前出战槽。
- 表面片数量固定、转移为有限邻域计算；齿轮与释放可以在发射短时段内用固定子步长。
  战斗仍按现有 `1/60s` 规则步长，不由 GPU 流体或动画帧率驱动。
- 每滴不新建独立材质、纹理或永久网格。复用遮罩/实例池并限制笔迹数量；
  油膜变化优先更新数据而非重新编译着色器，遵守既有预热与资源释放边界。

## 实现顺序与验收

| 阶段 | 可交付内容 | 完成标准 |
| --- | --- | --- |
| A：数值台架 | 接触区/供油/损耗纯数据模型，受控发射和轴尖接触对照 | 正负趋势、能量和油量记账成立；无油旧基线一致 |
| B：直接保养 | 实际模型滴油、涂抹、擦拭、开盖、拨动；基础传动、握持及接地效果 | 落点与效果对应，可重复试验、保存/取消，普通玩家可以继续直接开战 |
| C：机构深化 | 补齐释放机构与可选活动部件；相对运动、角动量及局部油转移 | 偏角和续航来自机构，实际运动可见，碰撞/结构损伤没有失效 |
| D：按收益扩展 | 污染、温度黏度、甩油、场地油迹或三维姿态 | 每项有可感知玩法价值与测量依据后再加，不作为第一版前提 |

阶段 A/B 建议先覆盖四组可理解的试验：“齿条/轴座润滑是否省力或提转速”、
“握柄油污在何种拉力下打滑”、“轴尖沾油是否难刹车”、“过量是否出现拖曳”。
陀螺的内部轴承减阻放在 C 阶段，不能为赶进度给固定中轴虚构加成。

至少验证以下边界，结果写出配置、单位、输入约束和版本：

| 对照试验 | 应观察的因果 |
| --- | --- |
| 未启用保养 vs 默认/旧存档迁移 | 原组装值、发射及战斗金标保持一致 |
| 固定做功：干净参考、适量、过量 | 损耗改变带来有上限的转速差；过量是否反转收益由参数/试验决定 |
| 固定抽拉速度、固定齿比 | 同一运动约束下转速一致，拉力/做功需求不同 |
| 同油量：齿面、壳面、被盖住的内面 | 接触部位不同效果不同；遮挡阻止穿透上油 |
| 左右镜像、模型旋转、不同屏幕尺寸 | 对称输入无额外横向偏置；镜像不对称按局部受力变化，不能按屏幕坐标随机偏转 |
| 同样握柄油污：轻拉、重拉、夹具固定 | 阈值内不滑；超过阈值可滑；固定夹具不受手滑影响 |
| 三种现有轴尖、同初始转速/方向/场地 | 同时记录轨迹、刹车距离和失速时间，不只比较最长续航 |
| 固定中轴、外壳涂油 | 无接触转移时不出现内部减阻收益 |
| 活动尖无外力矩、单独转子/锁死极限 | 总角动量成立，能量不增加，锁死极限与对应整体惯量一致 |
| 局部重损 + 最佳润滑 + 供能区 | 仍可能结构失衡停转，不能润滑修复结构 |
| 滴油、铺展、擦拭、上限、撤销 | 油量守恒、可重现、不因命令频率无限增加或负值 |
| 保存/取消、换槽/换件、试用、刷新 | 草稿隔离、状态键正确、不污染经济和装备 |
| 相同命令与规则步长，不同渲染帧率 | 相同结果；渲染暂停不继续出油或消耗状态 |

第一轮不预先承诺“提升 5%/10%”或“偏角 3°”。先扫描油量、覆盖、载荷和速度，
找出因果错误，再用真实标准/重外缘/偏心配置与三个轴尖调平衡。
对照时区分“相同输入做功”和“相同初始转速”；前者观察整体收益，
后者隔离接地/轴承续航。试验读数不要计入既有实验室 XP 指纹，避免无限滴油刷经验。

按范围执行 `verify:lab`、`verify:showroom`、`verify:worlds`、

## 资料与证据边界

以下资料于 2026-09-23 核对。它们支持物理机制，不能直接给出本项目模型的系数。

- **[S1] SKF：[轴承摩擦、功率损耗和启动扭矩](https://www.skf.com/cn/products/rolling-bearings/principles-of-rolling-bearing-selection/bearing-selection-process/operating-temperature-and-speed/bearing-friction-power-loss-and-starting-torque)**。
  将总摩擦力矩分为滚动、滑动、密封与拖曳，说明润滑状态与黏滞损耗的关系。
  其转速曲线不是“油量曲线”，公式的工程单位也不直接套入本项目平衡单位。
- **[S2] Nye：[Gears](https://www.nyelubricants.com/gears)**。
  支持适当润滑降低齿轮摩擦、磨损、噪声和热量；指出油/脂选择、负载、温度及
  塑料/弹性体兼容性需要按实际材料验证。本提案首期一种兼容油是玩法简化。
- **[S3] igus：[Dry-running & maintenance-free iglide plain bearings](https://www.igus.ca/plastic-bearings/iglide-zero-lubrication)**。
  说明部分自润滑材料无需额外油脂，以及外加油脂与尘污附着的关联。
  这不证明本项目现有轴座就是该材料，也不意味着所有塑料轴承都免润滑。

握持失稳、卡爪脱离和自由轴尖的方程是一般力学推导与项目设计建议；
当前没有对应实物机构实验。所有收益幅度、触发阈值、流动系数和性能预算均待验证。
