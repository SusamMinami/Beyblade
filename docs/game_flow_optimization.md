# 游戏流程优化

适用：Web。2026-09-17。分析依据为当前源码和完整浏览器路径；本轮执行项已实现并通过功能验证。

## 流程诊断与优先级

| 环节 | 当前断点 | 本轮执行 |
| --- | --- | --- |
| 选择任务 | 先展示长剧情，对手、过关目标和准备入口较靠后 | 前置对手、目标、当前配置；剧情与补充情报渐进展开 |
| 战前准备 | 离开任务页后缺少明确的约战上下文；实验室“对战”固定进入自由地图 | 保存本标签页准备目标，复用三处现有导航返回同一任务，刷新后仍可返回 |
| 失败到调整 | 结算有数据，没有明确的下一次尝试；大量报告占据主要空间 | 从实际出界、供能与自身损伤给一条建议，连接真实改装槽；详细数据折叠保留 |
| 中途打断 | 暂停只有继续切换；失焦没有清键/自动暂停；缺少明确退出路径 | 暂停面板可继续或退出且说明不结算；失焦清除输入，回到页面由玩家主动继续 |

优先级是减少迷路与无效操作，再让战斗反馈转化为下一次选择。本轮不调整物理版本、
AI 强度、零件价格、所有权、奖励或关卡解锁，不暗中代玩家购买与装备。
未开放任务仍可预览，准备上下文不能成为绕过解锁的入口。

## Direction contract

THESIS：让每一场约战都有可返回的准备路径和可执行的下一步。
OWN-WORLD：继承任务纸色面板、现有游戏导航与青黄战斗信号，不换皮。
STORY：先知道打谁和怎样过关，再准备；失败后知道改哪里；中断后安全继续。
FIRST VIEWPORT：任务页先放对手、目标与配置，复用底部出战按钮；结果页先放结果和一条建议，明细折叠；准备页面复用现有导航返回约战。
FORM：既有页面局部流程扩展，无需方向抽签。暂停用于保护进行中的对局。
FINISH：unreviewed and undocumented is unfinished; this build ends with the finish review, the verdict, DESIGN.md, and every shipping raster carrying its provenance

## 实施与验证

已实现：

- 任务页先显示对手、目标和当前出战配置，约战缘由与对手情报可展开阅读。
- 仅可挑战任务能建立准备目标；目标存于当前标签页 `sessionStorage`，
  改装、测试、陈列室可连续切换，刷新后仍返回原任务（包括重打旧关）。
  明确切换自由对战或开始一局后清除准备目标；经济与任务存档不增加字段。
- 结算建议读取玩家自己的损伤、失衡和占区时间，出界先提示控制。
  需要调整零件时，“检查某部位”定位到现有改装槽，不购买或更换零件。
  完整战报默认折叠；金币已到账、继续旅程/重试保持可见。
- 待发状态可返回；运行中点击计时器或按 Escape 暂停。
  原生暂停弹窗提供继续/退出；切出窗口自动暂停并清空键盘、摇杆与指针捕获。
  继续需重新输入，退出不写战历、不发奖励。

功能证据：

- `npm test`：29 项通过；`npm run build` 通过，保留现有 Three.js 约 888 kB 分包警告。
- `npm run verify:flow`：41 项通过，包含真实求解器结束、刷新返回旧关、
  锁定预览隔离、暂停冻结、指针释放、退出不结算与完成奖励去重，
  以及全新玩家首战 180 金币到账和首件零件购买引导。
- `verify:campaign` 65、`verify:lab` 27、`verify:showroom` 25、`verify:battle-ui` 20 项通过。
- 实验室回归将弹窗选择器限定到 `.lab-view`；战斗回归改用暂停面板的继续按钮。
- 桌面 1440×1000、手机浏览器 390×844 的当前证据位于
  [flow 目录](../.impeccable/review/flow/)。
- [独立验收](../.impeccable/review/flow/finish-review.md)结论为 **ship**，
  范围为八张静态截图与指定流程源码核实；未独立复跑上述功能检查。
  环境无专用评审代理，由独立通用代理替代完成。

边界：不是手机真机性能结论；未改变求解器、地图模型、难度、价格或奖励。
第二轮的教学与成长扩展另见对应文档，不混入本轮验收结论；难度与局长仍待试玩。
