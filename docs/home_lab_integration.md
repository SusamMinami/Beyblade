# 主页成长与共享组装实验室

2026-09-24 用户要求后的 Web 实现。本页所述统一组装界面与场景复用尚未移植 Godot。

## 当前入口

- `/#home` 或不带 hash：按新手进度进入；完成引导后使用已装备展示舞台作为主页。
- `/#collection`：直接进入同一陈列区。已制作的全息陈列舱与冠军竞技舞台继续复用。
- `/#lab`：测试室右侧“改装保养”进入原组装界面的保养模式。
- `/#assembly`：统一组装入口，保留原三陀螺切换、五件换装和 DIY；
  顶部工具栏切换“陀螺 / 发射器 / 保养”，场景菜单选择实验室。
- 旧 `/#maintenance`、`/#launcher` 分别映射到组装中的保养、发射器模式，
  地址归一为 `/#assembly`，不再创建独立页面。左上品牌按钮返回主页。

初次启动沿用两场教学流程（首场发射训练，首次购买，第二场训练）。
完成或跳过引导后再次从主页进入，即展示实际装备陀螺。

## 剧情与既有经验

新玩家从共享的极简空间开始。开启“随剧情升级”时，第一章末战
`rival-arrives` 完成后推荐童年书桌；未完成第一章也可主动选择书桌。

第二章“修好它，不换掉它”的末战 `choose-a-line` 完成后：

1. 实验室经验不足 120 时补到 120；高于 120 保持原值。
2. 通过现有 LV.2 规则解锁冠军舞台；无金币或额外物品奖励。
3. 开启“随剧情升级”时，采用精密实验室与冠军舞台。

这是一条经验下限规则；反复结算、重新进入或读取旧存档不叠加经验。
也可继续通过既有测试积累经验，提前达到 LV.2 后手动选择场景。
原组装场景菜单、实验室设置与展示舞台面板支持“随剧情升级”；
组装与测试共用实验室偏好，展示舞台使用独立偏好。手动选房间或舞台关闭
对应开关，保留玩家选择。再次开启恢复剧情推荐。任何进度都可选回极简空间。

旧档已选精密实验室，或已经持有冠军舞台的展示选择，默认为手动偏好。
早期旧档没有记录“主动选回童年书桌”的历史，无法追溯；此类初级默认场景
按剧情升级，玩家可在设置中关闭。解锁预览仍不修改装备或所有权。

## 场景与交互

原组装的 `ThreeStage` 与工具模式的 `MaintenanceStage` 都借用
`LabStage.scene`、roomSets 缓存、原有反射环境和灯光。
极简底座由 `workshop-room.js` 统一生成；童年书桌与精密实验室继续使用真实资源，
不复制一套房间。组装、工具、测试和陈列室共用一个 WebGLRenderer。
进入组装时隐藏测试样本、扫描环、风场和透明护罩，调整场景与装备的相对位置；
离开后恢复场景原点、测试对象及视角。异步载入不能抢回已经转交的画布。

所有房间都沿用原组装的纸色、黑字与蓝色控件；房间升级只改变真实场景，
不切换到另一套深色工作台皮肤。保养与换装共用草稿，可直接触及展开的内部零件，
无遮挡解谜。
油膜坐标保持部件局部空间，视觉缩放不改变油量或物理计算。
下方工具控制台可滚动，保存操作常驻底部；短屏压缩工具栏以保留模型操作空间。

保存换装或保养后留在当前模式。“撤回未保存修改”恢复草稿并返回陀螺组装。
组装内部切换工具或房间保留草稿；离开组装放弃未保存修改。
购买所有权立即保存，换装/保养草稿保存后才用于对战；已经完成的购买不会撤销。
保存失败保留草稿并回滚内存装备，场景偏好写入失败也不会提前提交。

## 验证

`npm run verify:assembly` 覆盖原组装点选与 DIY、三陀螺切换、工具与场景草稿保留、
分章升级、保存回滚、刷新恢复、320×568 保存可达及共享场景归还。
`npm run verify:home` 覆盖新旧存档、剧情门槛、重复保存、手动偏好、
锁定预览、保存失败、移动端保存按钮、共享场景及连续快速导航。
原有 `verify:maintenance`、`verify:launcher-outfit`、`verify:lab`、
`verify:showroom`、`verify:flow`、`verify:worlds` 继续约束既有行为。
本次合并结果与截图见[组装合并验证](../.impeccable/review/assembly-merge/verification.md)。
此前 `.impeccable/review/home-lab/` 保留为当时独立工具入口的历史证据。
