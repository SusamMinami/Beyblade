# Web 结构损伤与加速区

适用：Web `2026.09.16-web-v4`。以下规则已实现；验收状态见文末。
Godot Jolt 实验、Worker 和旧二进制协议尚未移植。

## 原实现诊断

v3 只有整机耐久与会恢复到零的碰撞失衡，重心、惯量和质量始终使用组装值；
障碍物只回弹与扣转速。因此不能表达某侧零件破损、长期偏心和带伤续航的因果关系。

## 当前实现规则

- 使用现有五个零件和 DIY 数据，每个零件分八个本体方向扇区。接触法线结合确定性旋转相位决定受撞位置。
- 碰撞冲量、攻击力、场地损伤系数决定载荷。载荷从外环传入锁扣、配重、中轴与轴尖；
  材料耐久、厚径比、凸翼和中轴高度影响抗损与应力集中。
- 裂损先产生变形，较重后产生等效掉块。按损失质量的一阶矩计算重心，重新计算惯量、
  刚度、稳定性和附加转速阻力。均匀损伤与单侧损伤的质量分布不同。
- 初始载荷分配比例为外环 0.64、锁扣 0.13、配重 0.17、中轴 0.09、轴尖 0.035，
  高度和倾斜增大内部传力（因此不是总和必须为 1 的能量分配）。
  零件容量为 `durability × 0.24 × 厚径比`；同向扇区承载 72%，相邻各 14%。
  扇区损伤超过 55% 后开始等效掉块，最大丢失该扇区 38% 质量。
- 不通过减小惯量提高当前角速度：碎片带走其角动量，破损不会免费加速。
- 两枚旋转外环贴靠时，凸齿反冲可将它们分离。反冲新增平动能量从双方旋转能量扣除，
  另有原接触耗散，避免原地无损推挤；这是圆形接触基础上的凸齿近似。
- 临时碰撞倾斜可恢复，永久结构失衡是恢复下限；加速区不修复任何零件。
- 严重锁扣／中轴／外环失效判结构破坏；没有达到解体阈值也可因偏心、擦地先停转。
- 回合后重置损伤，不改玩家所有权、物价、金币或永久磨损。

加速区 A/B/C 位于地图内侧空地，每八秒换站，点亮七秒、冷却一秒。
全场一次只供能一站。入区按扭矩／当前惯量补转，最高到配置最大转速的 92%。
扭矩预算为 6.4；严重失衡会降低供能效率。圆盘半径为 1.25，遗迹缩至 1.0。
双方同时入区时各获 35% 供能；低于停转阈值不能复活。AI 追踪站点、刹车守位，
有人占区时尝试撞开，并绕开实体障碍。75 秒回合上限保留。

这些是**游戏平衡单位下的确定性降阶模型**，不是有限元、真实材料断裂或 SI 单位应力。
接触仍为平面圆形近似，DIY 半径参与碰撞，凸翼不是逐三角形刚体接触。
碎片视觉不作为独立可碰撞刚体；损伤使用参数化等效刚度与阻力。
固定输入与固定步长可复现；Web 未实现完整恢复快照或跨端锁步互通。

## Direction contract

THESIS：把争夺供能和带伤失速变成看得懂的对战。
OWN-WORLD：继承竖屏赛场、青色玩家、对手专属涂装、纸色结算和信号黄活动区。
STORY：认出对手，追随点亮区，撞开守区者，读懂哪一部分决定胜负。
FIRST VIEWPORT：原双人 HUD 下集成一行区位倒计时；原状态栏显示结构状态，赛场内标 A/B/C。
FORM：现有战斗页局部扩展；无需方向抽签。损伤直接落在五个可辨认零件，结束时突出胜因与争夺数据。
FINISH：unreviewed and undocumented is unfinished; this build ends with the finish review, the verdict, DESIGN.md, and every shipping raster carrying its provenance

## 验证

- `npm run verify:structure`：69 项通过，证据在
  [physics.json](../.impeccable/review/structure/physics.json)。
  包含无损基准、材料/几何抗损、方向和相位、质量丢失/重心/惯量、
  结构失衡不恢复、对称掉块、重置、供能上下限、争夺、重损区内停转、
  障碍净空、模拟确定性、障碍损伤、接触反冲的能量与动量，以及十场真实配置 AI。
- 固定种子对照：十场默认玩家挂机，争夺 AI 胜九场；标准双方抢区对局产生 21 次有效接触，
  玩家占区约 6.37s、补转约 29.95，最终约 9.8s 结束。它说明争夺增加接触，
  不代表人类最优策略或全配置胜率；高攻击黑曜仍可因自身耗损先停转。
- 健康陀螺入区净补转；通过实际载荷函数造成局部重损后，即使强制停留区内仍净掉转并
  `structural_spin_out`。这个受控边界案例不被描述为每局自然出现的统计频率。
- 既有 `npm test`：29 项通过；`verify:worlds`：31 项通过；
  `verify:campaign`：65 项通过；构建通过，保留已有 Three.js 大分块提示。
- 新战斗 UI 检查 20 项通过；普通终结停留实测约 859ms，减少动态为 0ms。
  独立通用子代理复核八张截图：**SHIP（静态范围）**，没有实质视觉修复项。
  证据与范围见 [最终验收记录](../.impeccable/review/structure/verification.md)。
