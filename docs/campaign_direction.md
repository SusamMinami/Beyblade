# 回声远征：任务与叙事设计

适用端：Web 原型。2026-09-16。

## 现状与问题

此前真正实现的任务只有木陀螺首战、首次购买零件、改装验证战。
首战固定 180 金币，之后胜利 120、失败 40。两场教学只要求完成，不要求获胜。
之后进入自由地图循环，没有章节、具名对手、复仇关系或明确终点。
实验室通过不同配置的首次测量获得经验；等级用于舞台与房间解锁，
没有剧情关系。三个出战槽、15 个零件、DIY 与五张地图已经可用。

缺口在于：玩家能提高参数，却不知道为了谁、为了什么而提高；新地图是菜单，
没有“我终于来到这里”的意味；陀螺更换零件之后没有记录共同经历的地方。

## 推荐故事：旧陀螺的公路片

暂名《回声远征》。不是被选中的神器，而是一只差点被丢掉的普通练习陀螺。
极轴联队推动统一规格赛事，街区的自制陀螺失去进入正式赛场的通道。
玩家从放学后的巷口出发，带着朋友的签名、修理师的推荐信、旧赛册，
最终在公开赛里为自制陀螺打回自己的名字。

“回声”是旅程名，不强行改名或替换玩家已有陀螺。三个真实出战槽均可参与。
核心情绪：被轻视 → 被理解 → 被看见 → 理解对手 → 被承认 → 回到老地方。
明确终点：击败罗彻，拿到自制资格，带着改变了的关系回到童年的玩具盘。

### 人物与冲突

| 人物 | 欲望与阻力 | 玩家关系 | 用战斗表达 |
| --- | --- | --- | --- |
| 阿砾 | 想让放学后的街头继续有人玩 | 伙伴 | 第一次战斗允许败局推进，鼓励再次出发 |
| 罗彻 | 曾被嘲笑，因此依靠联队身份证明自己 | 宿敌，最后成为互相承认的对手 | 四次交手分别偏攻击、偏心重击、回归稳定、稳定续航 |
| 阿岑 | 不愿看到有价值的旧东西被轻易丢弃 | 修理师导师 | 标准盘学稳定、复合盘学路线，给改装以目的 |
| 韩峥 | 相信统一规格才能管理竞技 | 制度性对手 | 耐久型资格审查、续航型半决赛，正面检验玩家策略 |
| 闻舟 | 保存老赛场和它的历史 | 见证人 | 用真实障碍与方形边界打破碗形场习惯 |

罗彻会回应上一次交手，而不是每张地图换一个只出现一次的坏人。
韩峥提出清楚可见的规则障碍；不通过模糊的“黑暗力量”替代具体矛盾。
不使用强制败北、永久摧毁玩家零件、强制付费或刷到指定数值才给剧情。

### 五章十战

| 章 | 战斗 | 地图 | 情节推进与学习目标 |
| --- | --- | --- | --- |
| 放学后，别散场 | 它还会转 / 罗彻的最后通牒 | 街头 ×2 | 找回旧陀螺；击败童年对手，获得远行理由；学会回盘心 |
| 修好它，不换掉它 | 修理铺的试盘 / 一块地面，两种答案 | 标准 / 复合 | 推荐信；理解重心、稳定和材质路线 |
| 没有厂牌的号码 | 没有厂牌的参赛者 / 他也换了零件 | 冠军 ×2 | 获得号码；宿敌改装后再战；理解高速与偏心风险 |
| 所有冠军都曾摔倒 | 断柱之间 / 摘下徽章的一局 | 遗迹 ×2 | 找到旧赛册；看见宿敌的脆弱；理解障碍与无回中心力 |
| 把名字打回来 | 把旧赛册摊开 / 回声，对阵黑曜 | 复合 / 冠军 | 自制资格与决赛；综合应用路线、配置与操控；回街头的结尾 |

修理铺与资格赛是现有地图的叙事用途；本轮不宣称新增可漫游城镇、NPC 模型、
修理铺场景或过场动画。冠军场和遗迹使用已有 3D 场景。

## 玩法闭环与当前实现边界

现有选场页加入“故事远征 / 自由对战”。`/#journey` 直接进入故事模式，
`/#map` 保留自由选场。陀螺陈列室有远征入口。教学未结束时，任务页提示先完成
或跳过引导，不把教学首战误记为主线战斗。

每关：当前冲突 → 对手姓名与陀螺、配置情报 → 主目标与选做挑战 →
带真实配置发射 → 真实模拟结算 → 胜败对白、纪念与下一关/复仇/改装。
第一关完成即可推进，其余关卡获胜推进。已完成关卡可重打，未开放关卡可预览，
但不能出战。明确给出前置任务名称。挑战不阻塞主线、不额外加金币。

首次通关给唯一纪念文案，持久化已过关列表和挑战列表；最近 40 次实际完成的
主线对战保留对手、地图、胜负、用时与基础零件快照。胜败都留下记录；
中断、预览、自由战不记主线进度。战历不是输入回放，也不完整保存 DIY 几何快照。
领取随结算自动完成，不增加手动领取步骤。旧存档添加 campaign 字段，不清空存档。

对手差异来自真实零件组合、外环 DIY、地图和固定种子，AI 会追踪供能点并争夺。
“偏重攻击 / 续航”是配置倾向，不宣称实现自适应 AI、专属主动技能或动态学习。
普通对战调参仍可用；主线是本地故事原型，不是排行榜或服务端权威战役。
对手强度与整段时长仍需人类试玩调优，自动化过关验证不等于难度验证。

`src/core/campaign-state.js`（进度与结算），`src/ui/campaign-panel.js`（选场页任务），
`src/main.js`（战斗接入），均相对于 Web 原型目录。

| 对手 | 识别特征 | 实际配置表达 |

| 阿砾 / 石子号 | 蜂蜜橙六瓣、蓝绿石芯 | 较小聚合物外环，轻巧、抗损较弱 |
| 罗彻 / 黑曜 | 紫黑刃冠、朱红三爪印 | 从三向凸翼到合金重击，再加厚回正，最终降低凸翼、偏重稳定 |

`src/data/opponent-identities.js` 同时提供模型涂装和计算器 DIY 输入，不通过隐藏属性
制造强度。模型使用现有五件式程序几何与材质，不新增可购买库存或 NPC 人体模型。

### 为什么比加日常任务更有动力

短期：眼前就是下一名对手，失败知道回哪里准备。
中期：同一宿敌换装再会，既有复仇也有“他也在成长”的压力。
长期：终点清楚，旅途纪念把配置成长转成共同经历。
归来：冠军之后仍回巷口，保留陀螺作为童年伙伴的价值。

## 后续扩展提案（未实现）

优先于增加更多打怪数量：

1. **有形的同行痕迹**：陈列室展示工具盒签名、号码牌和修补纹路，故事纪念可点开；
   保留修改前零件的“老照片”，不把伤痕变成强制维修付费。
2. **有反应的宿敌**：罗彻在下一章按玩家常用战术选择两种可解释的配置之一，
   战前明确展示变化；不读实时输入作弊。失败后的对白对应真实终结原因。
3. **地方人物支线**：阿砾“最后一个离开的人”（赢回街头挑战）、阿岑“给旧零件
   一次机会”（自选旧件完成挑战）、闻舟“绕远也能赢”（实测障碍路线挑战）。
   每条有开端和收尾；不做重复十次的计数任务。
4. **旅途分岔**：三条可选的训练经历影响称号和对话，不制造不可逆数值劣势。
   实验室报告可解锁情报，但不强迫为推进剧情反复扫描。
5. **决赛镜像**：未来记录玩家早期配置，罗彻用“过去的你”作陪练；
   需要先做好对局快照和公平 AI，不能用换标签冒充该能力。

如果希望更奇异，可另立“失落赛场巡礼”（环境叙事与考古）或“退休冠军带徒弟”
（成就来自培养下一代）。当前推荐先把童年、旅行、宿敌这条关系做扎实；
它与现有场景、组装、测试资产的匹配度最高。

## Direction contract

THESIS：在现有地图页扩充一张清楚的挑战书，让玩家知道为何出发、要赢过谁。
OWN-WORLD：继承现有白纸、黑线、电蓝、信号黄和中文系统字体；保留真实场景背景。
STORY：先读冲突，再看对手与目标，准备后发射，结算后看到关系变化。
FIRST VIEWPORT：顶部双模式切换；中部场景；下部可滚动任务正文；底部固定出战按钮。
FORM：现有选场页的局部扩展，无新视觉世界、无抽签；详情折叠展示战历和纪念。
FINISH：unreviewed and undocumented is unfinished; this build ends with the finish review, the verdict, DESIGN.md, and every shipping raster carrying its provenance
