# 第二轮：学会操作，看见成长

适用 Web，2026-09-17。执行范围已实现；功能验证与验收边界见下文。

## 执行范围

- 前两场沿用已有训练阶段和真实求解器。待发只强调直接发射；运行后依次提示
  轻推操控、追踪当下亮区、确认实际补转。提示不阻塞比赛或奖励，仍可跳过。
- 首次购买提供显式的零件查看入口，复用库存、价格、购买弹窗。第二场展示相对
  首次出战的配置变化，不把数值变化说成必然胜利。
- 每个既有出战槽保留最近一次已结束比赛的配置/DIY快照，改装和任务准备可比较
  当前配置的五项理论评分；结果保留本次与此前配置对比。弃赛不覆盖记录。
  旧存档没有快照时明确说明，不虚构基线。
- 五章结尾各有一段人物回应，首通结算连接下一站；已解锁回应可在任务页回看，
  重打不当作再次首通，未开放章节不剧透。
- 保留既有难度、局长、物理和经济，难度与局长调整仍需要人类试玩证据。

## Direction contract

THESIS：操作后得到确认，改装后看见取舍，通关后知道为何继续。
OWN-WORLD：沿用纸色任务/结算与青黄战斗信号；固定竖屏、模型与舞台不变。
STORY：发射、轻推、抢区逐步学习；首战留下参照，改装后再试；同行人回应每段成长。
FIRST VIEWPORT：战斗复用一块短教学提示；改装在出战槽下提供折叠对比，任务准备对比渐进展开；章节回应接在结算剧情中。
FORM：既有界面的局部扩展，不加开场仪式、不新增阻断弹窗。
FINISH：unreviewed and undocumented is unfinished; this build ends with the finish review, the verdict, DESIGN.md, and every shipping raster carrying its provenance

## 实施与验证

已实现：

- 教学从发射、轻推到抢区逐步推进。运行中有效操控超过阈值才确认轻推，
  真实 `spinHarvested > 0` 才确认补转；区域轮换/冷却更新提示，比赛结束隐藏教学。
- 购买引导连接现有部位与购买弹窗；取消不扣款，第二场显示理论评分取舍。
- 配置参照取自真实参赛前的快照，完成后每槽最多保留一份；保存基础零件及 DIY，
  不混入库存或经济权限。结果使用旧参照和本场快照比较，然后写入新参照。
- 改装页对比可折叠，展开时暂隐教学、保留底部操作；DIY 编辑时隐藏对比。
  任务页与结果页沿用已有可滚动内容区及固定主要操作。
- 五章各有一段首通回应与下一站行动，任务页按已完成事实提供回看。
  旧存档可从已有章节进度恢复回信，不补发奖励、不暴露未解锁内容。

验证证据位于 [growth 目录](../.impeccable/review/growth/)：

- `npm test`：29 项通过；`npm run build` 通过。仍有既有 Three.js 大分包提示。
- `npm run verify:growth`：57 项通过；包含两场真实训练、操控提示、取消购买、
  原价购买、刷新恢复、跨槽空状态、弃赛保护及结果对比。纯逻辑检查包含
  DIY 变化、实际补转判定、存档校验、十关首通/重打与章节锁定边界。
- `verify:campaign` 65、`verify:flow` 41、`verify:battle-ui` 20 项通过。
- `node tools/verify-chapter.mjs`：11 项通过。隔离存档预置第一关完成和已拥有的低重心核心，
  随后使用真实求解器完成罗彻首通、前往修理铺与重打；验证首通回应、下一站和奖励边界。
- 截图覆盖 390×844 和 1440×1000 的发射、轻推、改装对比、结果对比和章节回信。
  回信截图为已通关存档迁移场景；结果对比来自真实训练结束。
- 静态设计扫描没有主级问题；分隔线颜色的 3 条重复提示已通过记录既有
  `flow-separator` 规范处理。视觉规范与 sidecar 已由独立文档代理增量合并。
- [独立验收](../.impeccable/review/growth/finish-review.md)结论为 **ship**，范围为
  十张截图、对应代码与所提供的检查结果，未独立复跑功能检查。
  环境没有专用评审代理，使用独立通用代理替代；额外的章节真实对局由主代理验证，
  不扩大静态视觉评审的范围。

人类学习效率、难度、局长与全程叙事节奏尚未验证；手机截图不是手机真机性能结论。
本轮没有新增模型或图片资产，没有修改物理、价格、奖励或关卡规则，也未移植 Godot。
