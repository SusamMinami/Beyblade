## 三槽九款，可以混搭

编号沿用原拆分：**05 齿条 → 06 传动芯组 → 07 连接头**。
外壳换色独立于性能；蓝、铜、青绿只是部件识别色，不代表稀有度。
这些部件是不同用途的选择，首批不设置套装加成。

| 槽位 | 型号 | 模型上的差别 | 设计收益 | 代价与条件 |
| --- | --- | --- | --- | --- |
| 05 齿条 | R01 循衡 | 连续聚合物背梁、标准加强筋 | 抽拉负担与刚性平衡 | 不追求最低往复惯量或最高刚性 |
| 05 齿条 | R02 轻羽 | 两条连续导轨、贯通减重窗、窄横筋、导向垫 | 降低往复件惯量，更容易快速起拉 | 大拉力下挠曲与弹性储能回弹更明显；不凭空设置随机跳齿 |
| 05 齿条 | R03 刚脊 | 全长嵌入金属背脊、可见固定铆钉 | 降低高载时的变形 | 往复质量增加，同样快速起拉需要更多力 |
| 06 芯组 | T01 恒比 | 上层 32 齿驱动轮 / 32 齿输出轮、完整轮辐面 | 均衡传动，作为新系统参考件 | 无极端速转或省力优势 |
| 06 芯组 | T02 超越 | 上层 36 / 28 齿、贯通轮辐、较小输出轮 | 同抽拉速度下有更高输出转速 | 同输出负载需要更大拉力；高惯量陀螺未必受益 |
| 06 芯组 | T03 厚积 | 上层 28 / 36 齿、较大输出轮与完整轮辐 | 较容易带起高惯量负载 | 同抽拉速度下转速较低 |
| 07 连接头 | C01 直联 | 单组支承、标准导向裙、三爪转子 | 导向长度与运转阻力平衡 | 不追求极短退出路径或最大支承跨度 |
| 07 连接头 | C02 瞬脱 | 短导向裙、窄转子辐条、退出让位斜面 | 缩短退出接触，降低转子惯量 | 对偏斜轴线的约束行程较短；脱离效果须等释放机构完成后验证 |
| 07 连接头 | C03 定轴 | 两组分离轴承、间隔柱、连续导向裙 | 增加支承跨度，抑制受载时的轴线偏斜 | 多一组支承与密封，拖曳和转动惯量增加 |

所有齿条保持相同齿距、装配长度和可用导向边界。本批不通过“更长齿条”
悄悄增加输入做功，也不改变 T 形拉柄的位置。
所有连接头保持原来的三爪位置、朝向、插入净空基准和 `TopMount`。
实际配合仍需后续接触验证；“定轴”不意味着自动修正玩家有意设定的发射角。

建议的三个试验组合：

- **均衡参考：R01 + T01 + C01**，作为新系统标定基准。
- **轻快试验：R02 + T02 + C02**，检验低惯量陀螺和快速抽拉；不保证重陀螺更强。
- **高载试验：R03 + T03 + C03**，检验较大拉力、高惯量负载与偏载支承。

玩家也可以只换一件，例如 R01 + T02 + C03。比较界面应显示各槽的贡献，
不把外壳颜色或完整套装作为生效条件。

## 传动结构与数值含义

三款芯组都由下层 **36 齿输入小齿轮**接收齿条运动。它与上层驱动轮共轴，
再驱动输出轴上的上层齿轮。芯组整体更换，不允许把不同套件的轮子随意拼接。

| 芯组 | 上层驱动 / 输出齿数 | 输出角速度 / 输入小齿轮角速度 | 理想输出扭矩 / 输入扭矩 |
| --- | --- | ---: | ---: |
| T01 | 32 / 32 | 1.000 | 1.000 |
| T02 | 36 / 28 | 1.286 | 0.778 |
| T03 | 28 / 36 | 0.778 | 1.286 |

表中是**新建几何对应的理想传动关系**，不是游戏转速提升百分比。
外啮合的输入和输出转向相反；表中仅列幅值，三款的转向关系相同。
齿距统一为 `0.046` 视觉单位，模数为 `0.046 / π`；
上层齿数之和恒为 64，因此中心距固定为 `64 × 模数 / 2`。
完整坐标与精确值由 `parts.json` 生成，不手工抄写近似值作为接口。

本次校验的是齿距、名义节圆与中心距。齿面仍采用简化梯形外观，
不是渐开线制造图；没有进行齿面碰撞、应力、疲劳、噪声或材料挠曲仿真。
不能把旧模型的装饰性齿数与这套新接口混用。

### 性能接入时采用同一份输入预算

沿用[保养方案](maintenance_lubrication_design.md)的有限做功约束：

```text
输入做功 = ∫ 抽拉力 × 齿条位移
陀螺动能 + 发射器残留动能 + 回位储能 + 总损耗 ≤ 输入做功 + 初始储能
输出角速度的运动上限 = 抽拉速度 / 输入节圆半径 × 芯组齿比
```

齿轮比不创造能量。固定做功、固定拉力和固定抽拉速度是三种不同试验；
增速芯组不能在三种情况下都无条件提高发射转速。齿条柔性需要区分可回收
弹性储能和真正损耗；不能把全部变形能直接删除。轴承和润滑损耗也不能再
与一个额外“部件效率加成”重复计算。

后续用当前真实陀螺配置比较有效初始转速、峰值抽拉力、输入做功、释放倾角、
发射器残留动能。不给 R02、T02、C02 预填未经验证的百分比。
前向发射速度与自转速度分开处理，不通过统一放大 `power` 同时提升两者。

现有无发射器属性的存档必须保持旧结果；新参考件要经过标定才能替代它。
接入时同步普通 `launch()` 与 `launchExplicit()`，把合法部件 ID 和相关状态
纳入双方对局快照。沿用现有三槽、所有权、购买与金币框架；本次的设计清单
不是可直接写入存档的正式部件注册表。

## 已补的装配关系

新资产采用 `launcher-performance-v1` 接口，只用于这套候选模型。
原整体发射器与上一版模块研究文件保留。

| 位置 | 这次完成的模型结构 | 仍需验证的范围 |
| --- | --- | --- |
| 齿条与固定导轨 | 统一截面和齿面；外壳与导轨中挖出贯通走廊 | 全行程接触、受载变形 |
| 齿条与抽拉柄 | 带销孔的端部舌片、独立销轴、拉柄内接合槽与销孔 | 销的保持与实际拆装动作 |
| 芯组与机身 | 托板、支承、支架；托板避让既有上盖支柱 | 紧固顺序和极限公差 |
| 芯组与连接头 | 贯穿底壳的轴孔、分段圆轴颈、六方输出端、匹配的六方孔 | 扭矩传递与制造公差 |
| 连接头固定部分 | 三处机身螺纹座、法兰孔和紧固件 | 真正的可制造螺纹与装配工具空间 |
| 连接头转动部分 | 与固定壳分离的转子、支承、三爪与导向结构 | 旋转接触、脱扣与上部释放开关的完整联动 |
| 陀螺端 | `TopMount = [0, -0.474, -0.12]`，原三爪位置保持 | 各实际陀螺形状的动态插拔与释放 |

回位弹簧有体积、独立节点和展开位置，但端部保持、变形与回位尚未求解。
外部释放滑钮继续保留；不能把这次“连接头部件建模”宣称为已经完成内部凸轮、
独立卡爪、回位和释放动作。主握柄接合结构也仍沿用上一阶段，未扩展到本批范围。

## 爆炸图作为升级界面的模型状态

这次导出保留两层结构：

1. **八个槽位根节点**：沿用上一版的编号、锚点和拆解向量。
   整机 GLB 带 `Launcher_Explode` 动画，第 1 → 60 帧；按 24 fps，时长约 2.46 秒。
2. **部件内检查节点**：芯组保留托板、输入转子、输出转子、轴承桥、回位弹簧；
   连接头分固定壳与转子；齿条保留主体、背脊、连接销。
   每组带局部轴心、运动类型和 `detailExplode` 位移，可在选中后继续展开。

每个 GLB 在“相同节点 + 材质 + 表面用途”内部合批。
不会把输入轮和输出轮仅因材质相同而合成一个不可单独转动的网格。
`surfaceRole` 是粗粒度识别标记，尚不是保养方案所需的完整接触副或油膜分区。

未来游戏内操作顺序：

1. 进入改装时由实际已装备模型拉近，打开上盖，再展开对应模块。
2. 点击模型上的 05 / 06 / 07 选择槽位；其余模块留在原位，当前件可继续局部展开。
3. 预览新件时只替换草稿显示，保持相同接口、观察角度与外壳颜色。
   锁定件可以看内部，但不修改所有权或已装备配置。
4. 确认替换后先将旧件沿拆解方向移出，再让新件沿同一路径装入。
   不用瞬移、整机重建或额外的假样品代替装配过程。
5. 取消恢复原部件；减少动态模式直接到达对应装配状态，仍可旋转和查看。

这是后续交互契约，本次没有新增游戏页面或装备保存逻辑。
导出的动画可直接预览；以后按槽位交互时，也可以用 `parts.json` 中的向量
对每个根节点独立插值。插值总是从记录的装配变换计算，不能每帧累加位移。
模型预览、战斗中的完整装配和资源缓存要使用相同合法配置，但可以选择不同显示层级。

本次检查通过：九款导出重新载入、27 种组合的共同定位、三款名义齿数/中心距、
轮毂与轴承高度间隙、独立运动节点、有限网格数据和三角面预算。
