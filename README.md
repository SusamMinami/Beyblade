# 战斗陀螺 / SPIN CORE

竖屏 3D 陀螺游戏：组装自己的五件式陀螺，改造发射器，直接在模型上保养，
通过发射、操控、碰撞和抢占供能区，完成“回声远征”五章十战。

**当前先在 `web-prototype/` 实现和验证，再移植 Godot。**
接手从 [文档导航](docs/README.md) 开始，开发约定见 [AGENTS.md](AGENTS.md)。
状态核对：2026-09-30；具体检查结果以对应记录为准。

## 启动与入口

```powershell
cd web-prototype
npm ci
npm run dev
```

打开 `http://127.0.0.1:5173/`。新存档进入可跳过的两场训练，
完成后从“我的陀螺基地”继续。

| 入口 | 用途 |
| --- | --- |
| `/#home`、`/#collection` | 主页、三出战槽、升降陈列与故事入口 |
| `/#assembly` | 五件组装、模型 DIY、发射器换装、保养 |
| `/#lab` | 测试、报告、实验室经验、设置与零件商店 |
| `/#journey` | 五章十战、任务情报、纪念与战历 |
| `/#map` | 五张场地的自由对战 |

旧 `/#launcher`、`/#maintenance` 进入组装中的对应工具，地址归一为 `/#assembly`。
详细操作和存档说明见 [Web 指南](web-prototype/README.md)。

## 玩法原则

- 五件结构：攻击环、核心锁扣、配重盘、驱动中轴、轴尖；真实配置影响惯量、稳定、
  抓地和受损后的运动。重外圈、低重心、橡胶/金属尖都有收益与代价。
- 发射区分转速、前向速度、方向、高度与倾角；传动与润滑受有限能量约束。
- 保养可选、可试验、可擦回，部件自动展开；不增加开盖谜题、消耗品收费或强制磨损。
- 物理可信以可解释、可复现为目标。质量与长度使用游戏平衡单位，
  不称克或毫米；模型与音效不决定胜负。
- 手机优先，保留键盘与触控。手机传感器微调属于待真机验证方向，
  不是当前操作入口。
