# 战斗陀螺 Web 验证原型

独立的 HTML / Three.js / Tone.js 版本。所有网页版源码、测试和依赖声明均位于
`web-prototype/`，不依赖 Godot 运行时。

**当前迭代顺序：先实现并验证 Web，再同步 Godot。** 新增界面系统可以逐步实现；
尚未接通的服务明确显示状态。此约定已写入根目录 `AGENTS.md`。

文档核对：2026-09-16。[按任务查找文档](../docs/README.md)；
视觉规范见 [DESIGN.md](DESIGN.md)，模型和地图见 [场景说明](../docs/battle_worlds.md)。

## 测试实验室

启动后打开 `http://127.0.0.1:5173/#lab`，或从改装页点击“测试室”。

- 默认童年书桌，LV.2 可在设置选择精密实验室。精密实验台的测量臂、透明罩与
  仪器来自 `../resources/test_lab/test_lab.glb`；童年书桌来自
  `../resources/battle_worlds/childhood_lab.glb`。两者展示同一真实配置陀螺。
- 重量/惯量、质心/偏心、环境平衡三种测试，复用现有游戏单位和计算器。
- 最近 40 份测试报告存入 v2 存档的 `lab` 字段，可导出 JSON。
- 每个配置每种测试首次完成加 30 经验；重复同条件测试不重复加经验。
  等级阈值为 `120 × (等级 − 1)²`；LV.2 可免费解锁高级展示舞台。
- 设置包含风力、地面、自动旋转、质心标记、画质；设备校准为可保存的基准自检流程。
- 陀螺库与现有三出战槽共用；零件商店复用金币、所有权、价格和购买规则。
- 钻石入口及余额已预留，明确显示“尚未开放”；不接入充值或虚构余额。
- 底部导航连接改装、测试、竞技场选择，未修改战斗物理。

`npm run verify:lab` 在独立浏览器上下文验证测试、记录恢复、经验去重、购买、
导航和手机布局，不改用户浏览器存档；截图写入 `../.impeccable/review/web/`。
需先启动 dev server，默认使用本机 Chrome，可通过 `CHROME_PATH` 指定浏览器，
通过 `LAB_TEST_URL` 指定验证地址。

## 陀螺陈列室与风场观察

- `/#collection` 是完整的陀螺选择页面；完成引导的玩家默认进入此页，原改装页保留。
- 参考图一对应“全息陈列舱”，默认拥有；参考图二对应“冠军竞技舞台”，
  实验室 LV.2（120 经验）解锁。右侧“展示舞台”可预览、解锁、装备。
  预览不会写入装备状态；离开再返回恢复已装备舞台。
- 陀螺切换使用 1.05 秒升降：旧陀螺下降，完全隐藏后提交现有出战槽选择，
  新陀螺从下方升起。期间禁止重复选择；减少动态效果时缩短至 0.22 秒。
- 五项性能条调用现有 `getBuildRatings`，没有新增另一套战斗属性。
- 实验室镜头已拉近；“近景 / 俯视”按钮可手动切换，俯视时裁去上方仪器，
  在屏幕上保留结果摘要。
- “风场”控制风速 0–12 m/s、流向 0–360°；0° 向北（−Z），90° 向东（+X）。
  这里表示空气移动的方向，不是气象学的来向。选项和报告一起保存。
- 显式测试持续 5.2 秒，旋转不受“自动展示旋转”开关限制。演示转速平滑加速、
  减速；风场驱动局部倾斜/偏移、箭头和轨迹。它是可视化演示，不是新的战斗
  求解器，屏幕转速也不是战斗 RPM。质量、惯量仍为游戏平衡单位。
- 两个新舞台的 GLB 位于 `../resources/showroom/`，源模型位于
  `../tools/art_source/showroom_holo.blend` 和 `showroom_arena.blend`。
  运行 `tools/build_showroom.py` 可重建；Web 与 Godot 的原实验台未替换。
- 实验室和陈列室共用一个 WebGL renderer，离开页面停止该页面的更新。
- `npm run verify:showroom` 在独立 Chrome 存档验证旋转、风场、升降时序、
  预览/解锁隔离、持久化、返回导航和减少动态效果。截图输出至
  `../.impeccable/review/showroom/`。手机验证为浏览器窗口，非真机性能测试。

后续接手先读 [协作约定](../AGENTS.md) 和本指南，按任务进入
[专题索引](../docs/README.md)。7 月交接只用于追溯历史，不再作为当前状态入口。

## 已实现

- 五层程序化 3D 陀螺：攻击环、核心锁扣、金属配重盘、驱动中轴、轴尖。
- 15 个正式零件和 `3^5 = 243` 种组合。
- 与 Godot `AssemblyCalculator` 对齐的质量、惯量、摩擦、续航、控制、攻击和耐久计算。
- 五张竞技场：标准碗形、冠军科幻（原金属高速）、复合材质、街头、浮空遗迹。
- 确定性固定步长 1v1 模拟、基础 AI、虚拟摇杆和键盘控制。
- 3D 发射器直接操作：拖动模型调方向与倾角，拖动箭头端点调方向和力度。
- Spin Out、Ring Out、Break 和超时判定。
- Tone.js 发射、旋转、碰撞与结算动态音效。
- 碰撞伤害、转速衰减、控制响应和移动速度实时调参。
- 配置、颜色、赏金、地图和调参结果本地保存。
- 白纸、黑色粗线、电蓝与橙色构成的涂鸦式准备界面。
- 固定 `9:16` 竖屏画布，组装模型作为主视觉，信息沿画面边缘分布。
- 组装页默认只显示陀螺；点选部件后才展开改装，其他部件自动半透明。
- 三个独立出战槽位支持左右横扫切换，并分别保存配置和颜色。
- 地图选择使用横向吸附卡片，一屏完成切换。
- 组装模型支持统一环绕视角、滚轮/双指缩放和视角复位。
- 15 个零件的价格、所有权、金币购买、余额不足反馈和性能差值确认。
- 战斗优先的新手训练：木质陀螺首战、固定金币奖励、首次购买和改装验证战。
- `v2` 本地存档保存零件所有权和教程进度，并兼容迁移 `v1` 配置。
- 战斗主题跟随地图切换，并使用近景镜头和实时操控方向反馈。
- 平移速度、最大移动距离和操控力随转速衰减，避免停转前滑步。
- 碰撞会累积失衡，抬高倾角并在严重时触发擦地掉转与控制衰减。
- 碰撞、Ring Out、转速衰退和倾斜危机通过场内效果和音效反馈，不遮挡战斗。
- 摇杆固定在战斗画面底部；陀螺上方只显示实时控制影响与施力方向。
- 已装备零件支持二次 DIY，可直接拖动模型上的蓝色、橙色、红色手柄调整尺寸、
  高度和轮廓起伏。
- DIY 顶栏提供正视、俯视、侧视、实时质量/惯量和 2 / 3 / 4 / 6 边对称延展；
  切换对称方式会保留已有改造。
- DIY 材料使用金币永久解锁，底栏只保留材料列表、保存和取消；质心继续直接标在
  3D 模型上。
- 组装待机时陀螺自动缓慢旋转，相机有轻微动态；操作后立即停止待机动画。
- 出战槽切换使用陀螺滚动入场，部件聚焦使用相机平滑移动。
- 出战槽轮播严格匹配左右操作方向，跨首尾时画外重排非目标陀螺，避免反向穿场。
- 选择不同零件时执行短暂的旧件拆出、新件装入动画。
- 组装预览会按 DIY 后的实际包围盒重新拟合模型，维持稳定的画面占比。
- 地图支持拖拽吸附切换；保留标准与复合场，金属场升级为冠军场，新增街头和方形遗迹。
- 发射箭头末端使用扩大的触控命中区，预览位置与模拟初始位置保持一致。
- 战斗中的双方转速、耐久和时间集中在顶栏；品牌、金币、声音及风险窗口隐藏。
- 胜利结算显示独立赏金牌、烟花和彩带；所有按钮统一提供短促音效和按压颜色反馈。


## 操作

- 组装：轻点模型选择具体部件，未选中的部件会变为半透明；轻点空白退出改装。
- 深度 DIY：再次点击已装备零件进入编辑；保存后写入当前出战槽，取消则丢弃草稿。
- 模型塑形：拖蓝色手柄改大小，拖橙色手柄改高度，拖红色手柄改轮廓起伏。
- 视角：在模型或背景上拖动都会环绕整个场景；滚轮或双指缩放。点击其他部位会
  平滑移动镜头并直接切换编辑目标。
- 出战槽：在空白区域横扫，或点击顶部左右触控区域切换三个陀螺。
- 解锁：灰色零件尚未拥有；金色钱币标记表示余额足够，点击后确认购买并自动装备。
- 地图：左右滑动卡片切换竞技场，底部只有一个确认按钮。
- 发射：拖动发射器/陀螺改变方向和倾角；拖动黄色箭头端点改变方向与力度，
  箭头长度即力度。
- 战斗：摇杆固定在屏幕底部；陀螺附近只显示控制影响，桌面仍支持
  `WASD` 或方向键。
- 新手训练：首次访问从木质陀螺战斗开始，可随时点击“跳过引导”退出训练。

## 技术说明

战斗逻辑使用固定 `1/60s` 步长的确定性二维模拟，Three.js 只负责三维表现。
这种结构便于快速调参、录制输入和复盘，也比浏览器刚体直接参与规则结算更适合作为
后续异步 PVP 的验证基础。Tone.js 在首次用户点击发射或声音按钮后启用音频上下文。

零件经济和教程进度位于 `src/core/progression.js`，三个出战槽位位于
`src/core/loadouts.js`；两者都不参与确定性战斗结算。
每个出战槽的 `customizations` 按基础零件 ID 保存 DIY 参数。改造后的质量、
质心和绕自旋轴惯量由 `AssemblyCalculator` 实时计算，其中惯量包含平行轴项。
材料所有权保存在 `ownedMaterialIds`；迁移旧存档时，已被任一配置使用的合法材料
会自动补为已拥有，避免升级后丢失已有改造。
本地存档键为 `spin-core-web-prototype-v2`；旧版
`spin-core-web-prototype-v1` 会在读取时保留金币、配置和已装备零件，并将原配置
迁移到第一个出战槽。

`BattleSimulation` 构造参数支持：

```js
new BattleSimulation({
  // ...
  diagnostics: true,
  logger: (message, telemetry) => console.info(message, telemetry),
});
```

每次有效碰撞会写入 `collisionLog` 并触发 `collision` 事件。`telemetry` 包含双方
碰撞前后的 `tilt`、`spin`、`imbalance`、`durability` 及对应变化量，方便导出后
分析平衡性。日志最多保留最近 200 次碰撞。

失衡、风险状态、发射高度、DIY 材料和组合惯量规则已有 Godot 对应实现。
本轮 Web 新增方形遗迹边界和石墩碰撞，模拟版本为 `2026.09.16-web-v3`；
Godot 与网络协议尚未迁移该扩展。旧地图继续通过固定种子金标检查。
